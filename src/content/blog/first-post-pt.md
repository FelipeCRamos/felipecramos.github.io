Tudo começou quando eu tive a ideia de rapidamente desenvolver um website para melhor mostrar minha experiência e coisas legais que eu estava aprendendo no dia a dia.

Claro que, com as maravilhsas coisas que as IA's tem feito todos os dias, eu rapidamente elaborei um prompt para me guiar até a minha visão.

# Tecnologias utilizadas

Eu estou hospedando esse site no github pages, um jeito gratuito de hospedar seus websites na internet. Mas tem um porém, ele apenas permite websites estáticos (nada de servidores permitidos por aqui).

Por causa disso, eu percebi que [astro.build](https://astro.build/) era a solução perfeita para esse tipo de coisa, é basicamente um web framework que gera (a partir de um código javascript) uma página estática que pode ser hospedada no github pages!

Então, eu pedi para o `claude` gerar o conteúdo desse site a partir do meu curriculo que eu forneci a ele, e txaram, aqui estamos!

Ajustei algumas coisinhas, adicionei outras, e agora tenho essa plataforma irada para mostrar minhas habilidades.

Espero que tenha gostado, até a próxima!
