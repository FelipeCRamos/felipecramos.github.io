It all started when i had the idea to quickly develop a website to better showcase my experience and cool things that i was learning on my daily basis.

With the amazing things AI is doing each day, i quickly ellaborated a prompt to guide me through my vision.

# Tech used

I'm hosting this page on github pages, a free way to host your website on the web. But there's a caveat, it only hosts static pages, no dynamic/server things allowed in here.

Because of that, i realized that [astro.build](https://astro.build/) was the perfect thing to be used here, it's basically a web framework that generates (from your javascript code) a static page that can be hosted by github pages!

That way, i asked `claude` to generate the content for the website given my resume and voilà, here we are!

Tweaked a few things, added other things, and now i have this cool platform to better showcase my habilities.

Hope you enjoyed, see ya.
